Patterns I learned

  1. Use the AI for judgment, and scripts for steps that must always happen. Applied four times: the job-search email, the gas CSV and email, job-board fetching, and the job-search log.
  2. Test with data where you already know the right answer. Twice the agent's own "proof" of a fix contained the bug. A fake earlier price exposed both in seconds.
  3. Verify against the system of record, not the agent's report. The agent called an iMessage "delivered" from an exit code, and a run "succeeded" without writing its log.
  4. Keep one source of truth. A stale job prompt overrode an updated skill, and each run inherited the last run's conclusions.
  5. Check the stronger model too. Claude Code first said a job didn't exist; it corrected itself because I required it to check hermes cron list first.

Feedback for the product

27 friction items logged over five days. These six would likely drive the most support tickets.
